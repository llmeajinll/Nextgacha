# 취소/환불/반품 정책

상태 표기와 문서 규칙은 [README](./README.md) 참고.

## 구매자 주문 취소
- 상태: 확정
- 정책: 구매자는 `상품 확인중`(송장 입력 전)인 주문만 직접 취소할 수 있다. 예약 상품도 같은 기준이다. 처리는 관리자 환불(`refundOrder`)과 같은 흐름(Toss 취소 → 재고·keep·usedPoint 복구)을 재사용한다.
- 예외: `배송중` 이후에는 취소할 수 없다 ([배송 후 반품/교환](#배송-후-반품교환-청약철회)).
- 이유: 지금은 관리자가 거절할 때만 환불되므로, 구매자는 문의 말고는 취소할 방법이 없다.
- 코드: 미구현. 재사용 대상 `src/app/api/postCheckToSending/route.ts:27` `refundOrder`
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (`상품 확인중`만, 예약 상품 포함)

## 배송 후 반품/교환 (청약철회)
- 상태: 확정
- 정책: 배송이 시작된 주문(`배송중`, `배송 완료`)은 환불하지 않는다. 불량품이면 같은 상품을 다시 보내는 **교환**만 한다.
  - 교환은 주문 상태를 추가해서 처리한다: `배송 완료` → `교환 요청` → `교환 완료`.
  - 불량 교환 배송비는 판매자가 부담한다.
  - 개봉한 가챠 상품은 청약철회 대상에서 제외한다고 상품 페이지와 결제 화면에 미리 알린다.
- 예외: 없음
- 이유: 가챠는 무엇이 나올지 모르는 상품이라 단순 변심 반품을 받지 않는다. 지금은 포트폴리오용이라 법적 의무가 없다([약관·개인정보처리방침·사업자 정보](./members.md#약관개인정보처리방침사업자-정보)).
- 다시 볼 때: 실제로 판매하게 되면 전자상거래법 제17조상 **개봉하지 않은 상품**은 받은 날부터 7일 안에 청약철회를 막을 수 없다. 그때 미개봉 반품 경로를 추가한다.
- 결정할 것: 교환 발송분을 재고에서 뺄지 (불량품을 회수해 폐기하면 새로 보내는 수량만큼 재고가 줄어든다)
- 코드: 미구현
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (배송 후 환불 없음, 불량품 교환만, 상태 추가)

## 부분 환불
- 상태: 확정
- 정책: 하지 않는다. 환불은 `상품 확인중` 주문의 주문 전체 취소만 있다.
- 이유: 배송 후 환불이 없어서([배송 후 반품/교환](#배송-후-반품교환-청약철회)) 상품 단위로 나눠 환불할 경우가 없다. 부분 환불을 하려면 배송비 재계산(5만 원 무료배송 기준이 깨질 때)과 포인트 분배 규칙도 필요하다.
- 코드: `src/app/api/postCheckToSending/route.ts:27` `refundOrder` (주문 전체만 처리)
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (하지 않음)
