# 회원/개인정보 정책

상태 표기와 문서 규칙은 [README](./README.md) 참고.

## 회원 탈퇴
- 상태: 확정
- 정책:
  - 진행 중인 주문(`상품 확인중`, `배송중`)이 있으면 탈퇴를 막는다.
  - 탈퇴 전에 남은 포인트가 사라진다고 알린다.
  - 작성한 리뷰·QnA는 작성자를 익명으로 바꿔 남긴다.
  - 주문 기록은 탈퇴 후에도 분리 보관한다: 계약·청약철회·대금결제 기록 5년, 소비자 불만·분쟁 기록 3년 (전자상거래법 시행령 제6조).
- 코드: 미구현. 관련 컬렉션 `userColl`, `cartColl`, `orderColl`, `reviewColl`, `qnaColl`
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (진행 중 주문 시 차단, 포인트 소멸 고지, 리뷰·QnA 익명화)

## 약관·개인정보처리방침·사업자 정보
- 상태: 확정
- 정책: 포트폴리오용 서비스로 보고 페이지를 만들지 않는다. 대신 푸터에 "실제로 판매하지 않는 포트폴리오 사이트입니다" 안내를 둔다.
- 방문 분석(Google Analytics 4): 운영 사이트는 Google 태그(GA4)로 방문 기록을 모은다. 개인정보처리방침을 쓰게 되면 아래를 넣는다.
  - 수집 항목: 방문한 페이지 주소(검색어·카테고리 쿼리 포함), 유입 경로, 브라우저·기기 정보, IP로 추정한 대략적 지역, GA 쿠키(`_ga`, `_ga_*`) 식별자. 이름·이메일·주문 정보는 보내지 않는다.
  - 목적: 서비스 이용 통계(많이 본 상품, 검색어, 유입 경로) 확인.
  - 처리 위탁·국외 이전: Google LLC(미국)에 위탁하며 데이터가 국외 서버에 저장된다. 보유 기간은 GA 데이터 보관 설정을 따른다.
  - 거부 방법: 브라우저 쿠키 차단 또는 Google 애널리틱스 차단 부가 기능(https://tools.google.com/dlpage/gaoptout).
  - 관리자 화면(`/manager/*`)은 수집하지 않는다.
- 다시 볼 때: 실제로 판매하게 되면 이용약관, 개인정보처리방침(개인정보보호법 제30조), 청약철회 안내, 사업자 정보 표시(전자상거래법 제10조)가 법적 의무가 된다. 이때 [배송 후 반품/교환](./refunds.md#배송-후-반품교환-청약철회)도 다시 본다.
- 코드: 미구현 (푸터 안내). GA는 `src/app/GoogleAnalytics.tsx`
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (포트폴리오, 푸터 안내만), 2026-11-11 GA4 방문 분석 항목 추가
