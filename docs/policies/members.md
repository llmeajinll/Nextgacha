# 회원/개인정보 정책

상태 표기와 문서 규칙은 [README](./README.md) 참고.

## 회원 탈퇴
- 상태: 미정
- 정책: 미정. 지금은 탈퇴 기능이 없다.
- 결정할 것:
  - 진행 중인 주문(`상품 확인중`, `배송중`)이 있을 때 탈퇴를 막을지
  - 남은 포인트 소멸 고지
  - 리뷰·QnA를 삭제할지, 익명으로 남길지
  - 주문 기록 보존: 전자상거래법상 계약·청약철회·대금결제 기록은 5년, 소비자 불만·분쟁 기록은 3년 보존 (시행령 제6조). 이 기간 동안은 탈퇴 후에도 주문 문서를 분리 보관해야 한다.
- 코드: 미구현. 관련 컬렉션 `userColl`, `cartColl`, `orderColl`, `reviewColl`, `qnaColl`
- 변경 이력: 2026-11-09 신설

## 약관·개인정보처리방침·사업자 정보
- 상태: 미정
- 정책: 미정. 이용약관, 개인정보처리방침(개인정보보호법 제30조), 청약철회 안내, 사업자 정보 표시(전자상거래법 제10조) 페이지가 없다.
- 이유: 실제로 판매한다면 법적 의무다. 포트폴리오 용도라면 우선순위가 낮다.
- 코드: 미구현
- 변경 이력: 2026-11-09 신설
