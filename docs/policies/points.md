# 포인트 정책

상태 표기와 문서 규칙은 [README](./README.md) 참고.

## 포인트 유효기간
- 상태: 확정
- 정책: 포인트는 만료되지 않는다.
- 이유: 만료를 두면 적립 건별로 기록해야 해서 `user.point` 숫자 하나로는 부족하다.
- 코드: 적립 `src/features/purchase/lib/orderPolicy.ts:58` (소계의 1%), 지급 `src/app/api/postSendingToFinish/route.ts:29`
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (만료 없음)

## 반품 시 적립 포인트 회수
- 상태: 확정
- 정책: 회수할 경우가 없다. 적립 포인트는 `배송 완료` 때 지급되고, 환불은 그 전(`상품 확인중`)에만 된다. 배송 후에는 환불 없이 교환만 한다([배송 후 반품/교환](./refunds.md#배송-후-반품교환-청약철회)).
- 다시 볼 때: 배송 후 환불 경로가 생기면 그때 회수 방법을 정한다.
- 코드: 지급 `src/app/api/postSendingToFinish/route.ts:29`
- 변경 이력: 2026-11-09 신설, 2026-11-11 확정 (해당 없음)
